# Thumbuild

AI-powered Youtube Thumbnail Gnenerator

**LIVE DEMO**: https://thumbuild-ff1i.vercel.app/

> Best viewed on Desktop

---
## Features

- User authentication (Sign Up/Login)
- Strong password validation
- Forgot Password with reset token
- AI thumbnail generation with Google Gemini
- Style, color scheme and aspect ratio options
- Personal gallery (My Creations)
- Download and delete thumbnails
- Responsive UI

---
## Tech Stack
- FrontEnd: React, TypeScript, Tailwind CSS
- Backend: Node.js, Express, TypeScript
- Database: MongoDB Atlas
- Auth: express-session + connect-mongo
- AI: Google Gemini
- Image Storage: Cloudinary
- Deployement: Vercel
